# hallooo – KI-Videos für TikTok

Werkstatt für KI-generierte TikTok-Videos: Ideen, Skripte, Tools und Abläufe an einem Ort.

## Ziel

Mit KI regelmäßig TikTok-Videos produzieren, eine Reichweite aufbauen und daraus ein Business machen.

## Ordnerstruktur

```
ideen/       Video-Ideen und Trends
skripte/     Texte und Hooks für einzelne Videos
prompts/     Prompts für Bild-, Video- und Stimmen-KI
tools/       Eigene Skripte (z. B. Untertitel, Schnitt, Upload-Vorbereitung)
fertig/      Notizen zu veröffentlichten Videos und wie sie gelaufen sind
```

## Ablauf pro Video

1. Idee festhalten (`ideen/`)
2. Skript mit starkem Hook in den ersten 2 Sekunden schreiben (`skripte/`)
3. Bilder, Clips und Stimme mit KI erzeugen (`prompts/`)
4. Schneiden, Untertitel einfügen, Format 9:16
5. Veröffentlichen und Ergebnis notieren (`fertig/`)

## Mit Claude Code arbeiten

Beispiele für Aufgaben:

- „Schreib mir 10 Video-Ideen zum Thema …“
- „Mach aus dieser Idee ein 30-Sekunden-Skript mit Hook“
- „Bau ein Skript, das automatisch Untertitel aus einer Audiodatei erzeugt“
